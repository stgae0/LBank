从实际使用体验来看，LBank这个平台有优点也有槽点。

**客服响应速度一般**。工作日白天问题基本能在1-2小时内得到回复，但晚上和周末就得等比较久了。而且客服的专业水平参差不齐，有时候问一个稍微复杂点的问题，对方也答不上来。

社区里对LBank的评价很两极分化。爱它的人觉得上币快、手续费低、活动多。不喜欢的人说它山寨币太多、有些币归零跑路、平台的风控措施不够严格。

这么说吧，如果你是那种喜欢"冲土狗"、玩新币的人，LBank确实是个不错的选择。但如果你是稳健型投资者，只想买卖主流币，那币安、OKX这些头部交易所可能更适合你。
